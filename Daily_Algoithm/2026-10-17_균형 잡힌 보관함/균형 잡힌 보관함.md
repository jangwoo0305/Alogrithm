# 균형 잡힌 보관함

- 출제일: 2026-10-17
- 카테고리·알고리즘: 배열, 누적 합
- 난이도: 하~중
- 예상 풀이 시간: 30~60분
- 출처: 창작 문제

## 사전 학습 개념
- C# 배열의 인덱스와 순회
- 정수형 `int`와 `long`의 표현 범위
- 배열 구간의 합

## 문제 설명
일렬로 놓인 N개의 보관함에 각각 무게가 A₁, A₂, …, Aₙ인 물건이 들어 있다. 보관함 위치는 왼쪽부터 1번부터 N번까지이다.

보관함 하나를 선택해 그 안의 물건을 모두 꺼낸다. 선택한 위치의 **왼쪽에 있는 물건의 무게 합**과 **오른쪽에 있는 물건의 무게 합**이 같으면, 그 위치를 **균형 위치**라고 한다. 꺼낸 물건의 무게는 어느 쪽 합에도 포함하지 않는다.

왼쪽이나 오른쪽에 보관함이 없으면 그쪽 무게 합은 0이다. 각 위치는 **원래 배열에서 독립적으로** 판단하며, 앞에서 꺼낸 물건이 다른 위치의 판단에 영향을 주지 않는다.

균형 위치의 개수와 가장 왼쪽 균형 위치의 번호를 구하라. 균형 위치가 없으면 `0 0`을 출력한다.

## 입력 형식
첫째 줄에 보관함의 개수 N이 주어진다.
둘째 줄에 각 보관함의 무게를 나타내는 정수 N개가 공백으로 구분되어 주어진다.

## 출력 형식
균형 위치의 개수와 가장 왼쪽 균형 위치의 번호를 공백으로 구분해 한 줄에 출력한다.
균형 위치가 없으면 `0 0`을 출력한다.

## 제약
- 1 ≤ N ≤ 100,000
- 0 ≤ Aᵢ ≤ 1,000,000,000
- 위치 번호는 1부터 시작한다.
- 입력으로 주어지는 수는 모두 정수이다.

## 예제 1
입력:
```text
5
2 1 3 1 2
```
출력:
```text
1 3
```
설명: 3번의 물건을 꺼내면 왼쪽 무게 합은 2 + 1 = 3, 오른쪽 무게 합은 1 + 2 = 3이다. 다른 위치에서는 두 합이 다르므로 균형 위치는 3번 하나이다.

## 예제 2
입력:
```text
4
0 0 0 0
```
출력:
```text
4 1
```
설명: 어느 위치를 선택해도 양쪽 무게 합이 모두 0이다. 균형 위치는 4개이고 가장 왼쪽은 1번이다.

## 예제 3
입력:
```text
3
1 2 4
```
출력:
```text
0 0
```
설명: 1번을 선택하면 양쪽 합은 0과 6, 2번이면 1과 4, 3번이면 3과 0이다. 균형 위치가 없다.
