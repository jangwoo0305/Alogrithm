# 창고 로봇의 최단 이동

**알고리즘 : 너비 우선 탐색(BFS)**  
난이도: 초급~중급 · 예상 풀이 시간: 30~60분

## 사전 학습 포인트

- 큐의 선입선출(FIFO)과 기본 연산
- BFS의 방문 처리와 최단 거리
- 격자 좌표의 상하좌우 이동과 범위 검사

## 출처

창작 문제

## 문제 설명

창고는 `R`행 `C`열의 격자로 표현된다. 각 칸은 다음 문자 중 하나이다.

- `.`: 이동할 수 있는 빈칸
- `#`: 이동할 수 없는 벽
- `S`: 로봇의 출발 위치
- `G`: 목적지

로봇은 한 번에 상하좌우로 인접한 칸 중 하나로 이동할 수 있다. 대각선으로 이동하거나 격자 밖으로 나갈 수 없으며, 벽을 통과할 수 없다. `S`와 `G`는 이동할 수 있는 칸이다.

출발 위치에서 목적지까지 도달하기 위한 **최소 이동 횟수**를 구하라. 도달할 수 없다면 `-1`을 출력한다.

이동 횟수는 칸 사이를 이동한 횟수이다. 출발 칸에 서 있는 상태의 이동 횟수는 `0`이다.

## 입력 형식

첫째 줄에 정수 `R`과 `C`가 공백으로 구분되어 주어진다.

다음 `R`개 줄에 창고 지도가 주어진다. 각 줄은 공백 없이 `C`개의 문자로 구성된다.

## 출력 형식

목적지까지의 최소 이동 횟수를 출력한다. 도달할 수 없다면 `-1`을 출력한다.

## 제약 조건

- `1 ≤ R, C ≤ 500`
- `R × C ≥ 2`
- 지도에는 `.`, `#`, `S`, `G`만 등장한다.
- `S`와 `G`는 각각 정확히 하나 존재하며 서로 다른 칸이다.

## 입출력 예시

### 예시 1 — 벽을 피해 이동하는 경우

입력:
```text
3 5
S#..G
.#.#.
.....
```

출력:
```text
8
```

설명: 아래쪽 통로로 벽을 돌아 목적지에 도달할 수 있다. 예를 들어 아래로 2번, 오른쪽으로 4번, 위로 2번 이동하면 총 8번이며, 더 짧은 경로는 없다.

### 예시 2 — 목적지에 도달할 수 없는 경우

입력:
```text
3 3
S..
###
..G
```

출력:
```text
-1
```

설명: 가운데 행 전체가 벽이므로 출발 위치에서 목적지로 이동할 수 없다.

### 예시 3 — 출발 위치와 목적지가 인접한 경우

입력:
```text
1 2
SG
```

출력:
```text
1
```

설명: 오른쪽으로 한 번 이동하면 목적지에 도달한다.
