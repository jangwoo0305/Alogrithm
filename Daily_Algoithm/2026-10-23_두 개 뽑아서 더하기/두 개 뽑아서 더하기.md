# 두 개 뽑아서 더하기

- 출제일: 2026-10-23
- 출처: 프로그래머스 68644번 [공식 문제](https://school.programmers.co.kr/learn/courses/30/lessons/68644)
- 카테고리·알고리즘: 배열, 정렬
- 난이도: 하~중(학습용 추정; 공식 등급 미확인)
- 예상 시간: 30~60분
- 설명은 자체 서술이며, 예제는 검산한 연습용 자체 예제다.

## 사전학습 개념
- 배열의 인덱스와 원소 접근
- 중복 값의 의미와 구분
- 오름차순 정렬과 배열 반환

## 문제 설명
정수가 저장된 배열 `numbers`가 주어진다. 배열에서 서로 다른 두 위치를 선택하고, 그 위치에 있는 두 값을 더한다. 선택할 수 있는 모든 위치 조합을 대상으로, 만들 수 있는 합을 구하는 문제다.

두 위치에 저장된 값이 같아도 위치가 다르면 선택할 수 있다. 반대로 하나의 원소를 두 번 선택해서 더하면 안 된다. 예를 들어 배열에 1이 하나뿐이면 그 원소만으로 1 + 1을 만들 수 없지만, 1이 두 위치에 있다면 두 원소를 함께 선택할 수 있다.

서로 다른 선택에서 같은 합이 나올 수 있다. 반환 배열에는 같은 합을 여러 번 넣지 않고 한 번씩만 포함해야 한다. 가능한 합을 모두 담은 뒤 작은 값부터 큰 값 순서로 반환하라. 원래 원소의 위치 순서를 반환하는 문제가 아니라, **만들 수 있는 합 자체**를 반환하는 문제다.

## 공식 C# 제출 형식
`Solution` 클래스의 다음 메서드를 구현한다.
```csharp
public int[] solution(int[] numbers)
```

| 항목 | 의미 |
|---|---|
| 입력 매개변수 `numbers` | 선택할 값들이 들어 있는 정수 배열 |
| 반환값 `int[]` | 서로 다른 위치의 두 원소로 만들 수 있는 합을 중복 없이 오름차순으로 담은 배열 |

공식 제출은 함수형이다. `Console.ReadLine()`으로 입력을 받거나 답을 출력하는 대신 메서드의 결과를 반환한다. 결과 배열의 길이는 만들 수 있는 서로 다른 합의 개수에 따라 달라진다.

## 제약
- `numbers`의 길이: 2 이상 100 이하
- 각 원소: 0 이상 100 이하의 정수
- 같은 값이 여러 위치에 있을 수 있다.
- 서로 다른 두 위치를 선택하므로 길이가 2인 배열도 유효한 입력이다.

## 연습용 자체 예제 1
입력 매개변수:
```text
numbers = [1, 1, 2]
```
반환값:
```text
[2, 3]
```
설명: 서로 다른 위치의 1과 1로 2를 만들 수 있다. 1과 2를 선택하면 3이다. 3을 만드는 선택이 여러 개여도 반환값에는 한 번만 포함한다.

## 연습용 자체 예제 2
입력 매개변수:
```text
numbers = [0, 3, 5]
```
반환값:
```text
[3, 5, 8]
```
설명: 두 원소의 선택으로 나오는 합은 0 + 3 = 3, 0 + 5 = 5, 3 + 5 = 8이다.

## 연습용 자체 예제 3
입력 매개변수:
```text
numbers = [100, 100]
```
반환값:
```text
[200]
```
설명: 서로 다른 두 위치를 선택할 수 있으며, 만들 수 있는 합은 200 하나다.
