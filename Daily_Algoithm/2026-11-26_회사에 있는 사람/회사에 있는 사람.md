# 회사에 있는 사람

- 출제일: 2026-11-26
- 출처: 백준 7785번 [공식 문제](https://acmicpc.net/problem/7785)
- 카테고리·알고리즘: 해시, 집합, 정렬
- 난이도: 하~중(학습용 추정, 공식 등급 확인 아님)
- 예상 풀이 시간: 30~60분

## 사전학습 개념

- 집합의 원소 추가와 제거
- 문자열 비교와 대소문자 구분
- 사전 순서와 역순 출력

## 문제 설명

직원들이 자유롭게 출퇴근하는 회사의 출입 기록이 주어진다. 각 기록에는 직원 이름과 행동이 적혀 있으며, 기록은 실제 발생한 순서대로 제공된다. enter는 회사에 들어왔다는 뜻이고 leave는 나갔다는 뜻이다. 모든 기록을 반영한 시점에 회사 안에 있는 직원들의 이름을 구한다.

동명이인은 없으므로 이름이 직원을 식별한다. 대소문자가 다르면 다른 직원이다. 한 직원은 나간 뒤 다시 들어올 수 있으므로, 이전에 출근했다는 사실만으로 최종 재실 여부가 결정되지는 않는다. 출력 대상은 한 번이라도 등장한 모든 직원이 아니라 마지막 기록까지 반영했을 때 남아 있는 직원이다.

남은 이름은 사전 순의 역순으로 출력한다. 출근한 순서나 마지막 행동의 순서로 출력하지 않는다. 문자열은 대소문자를 구분해 비교하며, 앞부분이 같으면 뒤에 이어지는 문자도 비교한다. 각 직원은 한 번만 출력한다. 아무도 남지 않은 경우 출력할 이름이 없으므로 이름 줄을 출력하지 않는다.

## 입력 형식

첫 줄에 출입 기록 수 n이 주어진다.
이어지는 n줄 각각에는 이름과 enter 또는 leave가 공백으로 구분되어 주어진다.

## 출력 형식

현재 회사에 있는 직원 이름을 사전 순의 역순으로 한 줄에 하나씩 출력한다.

## 제약

- 2 ≤ n ≤ 1,000,000
- 이름은 영문 대소문자로 이루어진 길이 5 이하의 문자열이다.
- 대소문자가 다른 이름은 서로 다르다.
- 기본 시간 제한 1초, 메모리 제한 256MB. 언어별 보정은 공식 안내를 따른다.

## 공식 C# 제출과 콘솔 연습

백준 공식 [언어 정보](https://help.acmicpc.net/language/info)에서 C# 6.0 (Mono) 지원을 확인했다. 표준입력을 읽고 표준출력으로 결과를 내보내는 콘솔 프로그램을 제출한다. 별도의 solution 함수 시그니처는 없다.

로컬 연습과 공식 제출의 입출력은 같다. 프로젝트는 기존 환경과 같은 net10.0이며, 공식 제출에서는 선택한 C# 버전이 지원하는 문법과 API를 사용한다.

## 연습용 자체 예제

### 예제 1

입력:
```text
4
Mina enter
Jin enter
Mina leave
Yuna enter
```

출력:
```text
Yuna
Jin
```

Mina는 나갔고 Jin과 Yuna가 남는다. 역순에서 Yuna가 먼저다.

### 예제 2

입력:
```text
5
Ann enter
Bob enter
Ann leave
Ann enter
Cody enter
```

출력:
```text
Cody
Bob
Ann
```

Ann은 퇴근 후 재입장했으므로 최종 명단에 포함된다. 세 이름을 역순으로 출력한다.

### 예제 3

입력:
```text
4
kim enter
Kim enter
kim leave
Lee enter
```

출력:
```text
Lee
Kim
```

kim과 Kim은 다른 직원이다. 소문자 kim만 나갔으므로 Kim은 남는다.
