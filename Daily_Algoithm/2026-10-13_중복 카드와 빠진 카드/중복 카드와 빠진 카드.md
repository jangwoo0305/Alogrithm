# 중복 카드와 빠진 카드

**알고리즘 : 배열**  
**난도 : 하**

## 사전 학습 포인트

- 배열 인덱스와 카드 번호의 대응
- 각 값이 나타난 횟수 세기
- 입력의 조건을 이용한 결과 검증

**출처 : 창작 문제**

## 문제 설명

번호가 1부터 N까지 적힌 카드가 원래 한 장씩 있었다. 카드를 정리하는 과정에서 카드 한 장이 사라지고, 다른 번호의 카드 한 장이 복제되었다. 따라서 현재도 카드가 N장 있지만, 어떤 번호는 없고 다른 번호는 정확히 두 번 나타난다.

현재 카드의 번호가 주어질 때, 빠진 번호와 두 번 나타난 번호를 찾으시오.

## 입력 형식

첫째 줄에 카드의 수 N이 주어진다. 둘째 줄에 현재 카드 N장의 번호가 공백으로 구분되어 주어진다. 카드가 나열된 순서에는 의미가 없다.

## 출력 형식

빠진 번호와 두 번 나타난 번호를 이 순서대로 공백으로 구분하여 출력한다.

## 제약 조건

- 2 ≤ N ≤ 200,000
- 각 카드 번호는 1 이상 N 이하의 정수이다.
- 1부터 N까지의 번호 중 정확히 하나는 나타나지 않고, 그와 다른 번호 하나는 정확히 두 번 나타난다. 나머지 번호는 각각 한 번씩 나타난다.

## 입출력 예시 1

입력

```text
5
3 1 5 3 4
```

출력

```text
2 3
```

## 입출력 예시 2

입력

```text
2
2 2
```

출력

```text
1 2
```

## 입출력 예시 3

입력

```text
6
1 6 2 4 5 1
```

출력

```text
3 1
```

## 예시 설명

- 예시 1: 2번 카드가 없고 3번 카드가 두 장이다.
- 예시 2: 카드가 두 장인 가장 작은 경우로, 1번 카드가 없고 2번 카드가 두 장이다.
- 예시 3: 3번 카드가 없고 1번 카드가 두 장이다.
