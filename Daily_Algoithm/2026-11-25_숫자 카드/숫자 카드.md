# 숫자 카드

- 출제일: 2026-11-25
- 출처: 백준 10815번 [공식 문제](https://acmicpc.net/problem/10815)
- 카테고리·알고리즘: 해시, 집합
- 난이도: 하~중(학습용 추정, 공식 등급 확인 아님)
- 예상 풀이 시간: 30~60분

## 사전학습 개념

- 정수와 음수의 입력 처리
- 집합의 원소와 포함 관계
- 입력 순서에 맞춘 결과 출력

## 문제 설명

정수 하나가 적힌 카드를 N장 가지고 있다. 가지고 있는 카드에는 같은 정수가 중복되어 있지 않다. 별도로 주어지는 M개의 정수 각각에 대해, 그 정수가 적힌 카드를 가지고 있는지 확인한다.

각 질문의 답은 보유 여부이다. 해당 정수의 카드가 있으면 1, 없으면 0을 출력한다. 질문 전체에서 일치한 개수를 합산하는 문제가 아니며, M개의 결과를 질문이 주어진 순서대로 모두 출력해야 한다.

질문에 답해도 카드를 사용하거나 버리지 않는다. 같은 정수가 여러 번 질문되면 매번 같은 보유 상태로 판단한다. 카드와 질문에는 음수와 0도 등장할 수 있으며, 부호까지 포함한 정수 값이 같아야 일치한다. 카드의 입력 순서와 질문의 순서는 서로 관련이 없다.

## 입력 형식

1. 첫 줄: 보유 카드 수 N.
2. 둘째 줄: 카드에 적힌 정수 N개를 공백으로 구분.
3. 셋째 줄: 질문 수 M.
4. 넷째 줄: 확인할 정수 M개를 공백으로 구분.

## 출력 형식

질문마다 보유하면 1, 아니면 0을 출력한다. 결과 M개를 공백으로 구분하여 한 줄에 출력한다.

## 제약

- 1 ≤ N, M ≤ 500,000
- 카드와 질문의 값: −10,000,000 이상 10,000,000 이하
- 보유 카드의 값은 서로 다르다.
- 기본 시간 제한: 2초, 메모리 제한: 256MB. 언어별 보정은 공식 안내를 따른다.

## 공식 C# 제출과 콘솔 연습

백준 공식 [언어 정보](https://help.acmicpc.net/language/info)에서 C# 6.0 (Mono) 지원을 확인했다. 진입점에서 표준입력을 읽고 표준출력에 답을 쓰는 프로그램으로 제출한다. 별도의 solution 함수 시그니처는 없다.

로컬 연습과 공식 제출의 입출력 형식은 같다. 저장소 프로젝트는 기존 프로젝트와 호환되는 net10.0을 사용한다. 공식 제출 시 선택한 C# 버전에서 지원하는 문법과 API를 사용한다.

## 연습용 자체 예제

### 예제 1

입력:
```text
3
-2 0 7
5
7 1 -2 0 -7
```

출력:
```text
1 0 1 1 0
```

7, −2, 0은 보유하고 1과 −7은 보유하지 않는다.

### 예제 2

입력:
```text
1
5
3
5 5 6
```

출력:
```text
1 1 0
```

5를 확인해도 카드는 없어지지 않아 두 질문 모두 1이다. 6은 없다.

### 예제 3

입력:
```text
2
-10000000 10000000
3
0 10000000 -10000000
```

출력:
```text
0 1 1
```

0은 없고 양 끝 경계값의 카드는 모두 있다.

공유 Daily_Algoithm/Daily_Algoithm.sln을 열고 날짜가 포함된 프로젝트를 선택한다. NumberCards.cs는 정확히 0바이트로 시작하며, 진입점과 풀이를 직접 작성한다.

공식 조건을 자체 표현한 학습 자료이다. 예제는 자체 제작했으며 원문 권리는 원저작자에게 있다.
