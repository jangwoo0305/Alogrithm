# 가장 붐빈 연속 기간

**알고리즘 : 배열**  
**난도 : 하**

## 사전 학습 포인트

- 배열의 인덱스와 연속 구간
- 여러 정수의 합과 최댓값 비교
- 동점일 때 가장 앞선 위치 선택

**출처 : 창작 문제**

## 문제 설명

전시관은 매일 방문자 수를 기록한다. 전체 N일 중 연속된 K일의 방문자 수 합계가 가장 큰 기간을 찾으려고 한다.

합계가 같은 기간이 여러 개라면 시작 날짜가 가장 빠른 기간을 선택한다. 날짜는 1일부터 N일까지 번호를 붙인다.

## 입력 형식

첫째 줄에 N과 K가 공백으로 구분되어 주어진다. 둘째 줄에 1일부터 N일까지의 방문자 수 N개가 순서대로 공백으로 구분되어 주어진다.

## 출력 형식

선택한 기간의 시작 날짜와 그 기간의 방문자 수 합계를 공백으로 구분하여 출력한다.

## 제약 조건

- 1 ≤ K ≤ N ≤ 200,000
- 각 날짜의 방문자 수는 0 이상 1,000,000 이하의 정수이다.
- 합계는 32비트 정수 범위를 넘을 수 있다.

## 입출력 예시 1

입력

```text
6 3
2 5 1 4 3 6
```

출력

```text
4 13
```

## 입출력 예시 2

입력

```text
5 2
4 3 1 6 1
```

출력

```text
1 7
```

## 입출력 예시 3

입력

```text
1 1
0
```

출력

```text
1 0
```

## 예시 설명

- 예시 1: 4일과 5일, 6일의 합계가 4 + 3 + 6 = 13으로 가장 크다.
- 예시 2: 1~2일, 3~4일, 4~5일의 합계가 모두 7이므로 시작 날짜가 가장 빠른 1일을 선택한다.
- 예시 3: 가능한 기간이 1일뿐이며 방문자 수 합계는 0이다.
