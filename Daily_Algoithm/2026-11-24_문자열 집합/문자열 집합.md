# 문자열 집합

- 출제일: 2026-11-24
- 출처: 백준 14425번 [공식 문제](https://acmicpc.net/problem/14425)
- 카테고리·알고리즘: 해시, 집합
- 난이도: 하(입문 학습용 추정, 공식 등급 확인 아님)
- 예상 풀이 시간: 30~60분

## 사전학습 개념

- 집합의 원소와 포함 관계
- 문자열 전체의 동등 비교
- 입력을 읽고 개수를 세는 반복문

## 문제 설명

기준이 되는 문자열 N개로 집합 S를 구성한다. 이어서 검사할 문자열 M개가 주어진다. 검사 문자열마다 S에 같은 문자열이 있는지 판단하고, 포함되는 검사 문자열의 총개수를 구한다.

일부 글자가 같거나 한 문자열이 다른 문자열 안에 들어 있다는 것만으로는 일치하지 않는다. 문자열 전체가 같아야 한다. 기준 문자열들은 서로 다르다. 검사 문자열에는 중복 금지 조건이 없으므로 같은 문자열이 여러 번 입력되면 각 입력을 별도로 검사한다. 검사 과정에서 S의 원소를 소비하거나 제거하지 않는다.

출력은 일치한 문자열 목록이 아니라 정수 하나이다. 모두 불일치하면 0, 모두 일치하면 M을 출력한다.

## 입력 형식

첫 줄: N과 M을 공백으로 구분한다.
다음 N줄: S의 문자열을 한 줄에 하나씩 입력한다.
그다음 M줄: 검사 문자열을 한 줄에 하나씩 입력한다.

## 출력 형식

S에 포함되는 검사 문자열의 개수를 한 줄에 출력한다.

## 제약

- 1 ≤ N, M ≤ 10,000
- 문자열은 영문 소문자로만 구성되며 길이는 500 이하이다.
- S 안에는 같은 문자열이 중복되지 않는다.
- 기본 시간 제한 2초, 메모리 제한 1536MB. 언어별 보정은 공식 안내를 따른다.

## 공식 C# 제출과 로컬 연습

백준 공식 [언어 정보](https://help.acmicpc.net/language/info)에 C# 6.0 (Mono)가 등록되어 있다. C# 콘솔 프로그램의 진입점에서 표준입력을 읽고 표준출력으로 결과를 출력한다. 프로그래머스식 solution 함수 시그니처는 없다.

로컬 연습도 위와 같은 입출력을 사용한다. 저장소 프로젝트는 기존 환경과 같은 net10.0이지만, 공식 제출에는 선택한 C# 언어 버전에서 지원하는 문법과 API를 사용한다.

## 연습용 자체 예제

### 예제 1

입력:
```text
3 4
cat
dog
bird
dog
cow
cat
fish
```

출력:
```text
2
```

dog와 cat은 S에 있고 cow와 fish는 없다.

### 예제 2

입력:
```text
2 3
apple
pear
app
apple
apple
```

출력:
```text
2
```

app은 apple 전체와 다르다. apple이 두 번 검사되므로 두 입력을 각각 센다.

### 예제 3

입력:
```text
1 1
a
b
```

출력:
```text
0
```

검사한 b는 S에 없다.
