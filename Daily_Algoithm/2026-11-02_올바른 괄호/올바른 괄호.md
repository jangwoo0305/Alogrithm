# 올바른 괄호

- 출제일: 2026-11-02
- 출처: 프로그래머스 12909번 [공식 문제](https://school.programmers.co.kr/learn/courses/30/lessons/12909?language=csharp)
- 카테고리: 스택·큐 / 알고리즘: 괄호 짝 판정
- 난이도: 하~중(학습용 추정, 공식 등급 미확인)
- 예상 시간: 30~60분

## 사전학습 개념
- 스택의 후입선출 개념
- 문자열의 문자와 순서
- bool 반환과 경계 조건

## 문제 설명
여는 소괄호와 닫는 소괄호로 이루어진 문자열이 주어진다. 입력 순서 그대로 읽었을 때 모든 괄호가 올바르게 짝지어지는지 판정한다.

여는 괄호는 반드시 그 뒤의 닫는 괄호와 연결되어야 한다. 괄호 안에 다른 괄호 쌍이 들어가거나, 완성된 여러 쌍이 나란히 놓이는 것은 허용된다. 대응할 여는 괄호보다 닫는 괄호가 먼저 등장하면 올바르지 않다. 끝까지 읽은 뒤에도 닫히지 않은 여는 괄호가 남아 있으면 올바르지 않다.

두 문자의 전체 개수가 같다는 사실만으로는 올바른 문자열이 되지 않는다. 문자 순서를 바꾸거나 괄호를 추가·삭제하지 않고 주어진 문자열 자체를 평가한다.

## 공식 C# 제출 형식
Solution 클래스에서 다음 메서드를 구현한다.
```csharp
public bool solution(string s)
```
- 매개변수 s: 검사할 괄호 문자열.
- 반환값: 전체 괄호가 올바르면 true, 그렇지 않으면 false.
- 함수형 제출이며 별도 표준입출력은 없다.

## 제약
- 문자열 길이: 1~100,000.
- 문자 종류: ( 또는 )만 포함한다.
- 설명은 자체 서술이다. 공식 원문은 출처 링크에서 확인할 수 있다.

## 연습용 자체 예제
| s | 반환값 |
|---|---|
| "(()())" | true |
| "())(" | false |
| "((())" | false |

1. 가장 바깥 괄호 안에 완성된 두 쌍이 들어 있다.
2. 세 번째 문자를 닫을 때 대응할 열린 괄호가 없으므로 실패한다.
3. 마지막까지 닫히지 않은 여는 괄호가 하나 남는다.

세 예제는 독립 검산한 자체 연습 데이터다.
