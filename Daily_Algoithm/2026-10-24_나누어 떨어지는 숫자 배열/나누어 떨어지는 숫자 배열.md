# 나누어 떨어지는 숫자 배열

- 출제일: 2026-10-24
- 출처: 프로그래머스 12910번 [공식 문제](https://school.programmers.co.kr/learn/courses/30/lessons/12910)
- 카테고리·알고리즘: 배열, 정렬
- 난이도: 하(학습용 추정; 공식 등급 미확인)
- 예상 시간: 30~60분(배열 처리와 경계 조건 확인 포함)
- 문제 설명은 자체 서술이며, 아래 예제는 검산한 연습용 자체 예제다.

## 사전학습 개념
- 배열 순회와 원소 선택
- 나머지 연산과 나누어떨어짐
- 배열 정렬과 반환값

## 문제 설명
자연수들이 들어 있는 배열 `arr`와 자연수 `divisor`가 주어진다. 배열에 있는 값들 중에서 `divisor`로 나눴을 때 나머지가 0인 값만 골라 결과 배열을 만들어야 한다.

결과에 포함되는 값은 반드시 원래 배열에 있던 값이어야 한다. 나눗셈의 몫을 반환하는 것이 아니다. 선택된 값들은 작은 값부터 큰 값 순서로 배치해서 반환한다. 원래 입력 순서를 그대로 유지할 필요는 없다.

조건을 만족하는 값이 하나도 없으면 빈 배열을 반환하지 않는다. 이 경우에는 **-1 하나만 들어 있는 배열 `[-1]`**을 반환한다. 조건에 맞는 값이 존재한다면 결과에 -1을 추가하지 않는다.

예를 들어 12가 배열에 있고 `divisor`가 4라면, 12는 나누어떨어지므로 결과의 후보가 된다. 이때 결과에 넣을 값은 몫인 3이 아니라 원래 값인 12다.

## 공식 C# 제출 형식
`Solution` 클래스에서 다음 메서드를 구현한다.
```csharp
public int[] solution(int[] arr, int divisor)
```

| 항목 | 의미 |
|---|---|
| `arr` | 검사할 자연수들이 담긴 정수 배열 |
| `divisor` | 각 원소가 나누어떨어지는지 판단할 자연수 |
| 반환값 `int[]` | 조건에 맞는 원소들을 오름차순으로 담은 배열. 없으면 `[-1]` |

공식 제출은 함수형이다. 표준입력으로 값을 받거나 결과를 출력하는 대신 메서드에서 배열을 반환한다. [공식 C# 페이지](https://school.programmers.co.kr/learn/courses/30/lessons/12910?language=csharp)에서 그대로 제출할 수 있다.

## 제약
- `arr`의 길이는 1 이상이다.
- `arr`의 원소는 자연수이며 서로 중복되지 않는다.
- `divisor`는 자연수이므로 0이 아니다.
- 공식 문제에는 배열 길이와 값의 구체적인 상한이 별도로 제시되지 않는다. 임의의 공식 상한을 추가하지 않는다.

## 연습용 자체 예제 1
입력 매개변수:
```text
arr = [12, 5, 8, 3]
divisor = 4
```
반환값:
```text
[8, 12]
```
설명: 12와 8이 4로 나누어떨어진다. 작은 값이 먼저 오도록 반환하므로 [8, 12]다.

## 연습용 자체 예제 2
입력 매개변수:
```text
arr = [7, 2, 9]
divisor = 1
```
반환값:
```text
[2, 7, 9]
```
설명: 모든 원소가 1로 나누어떨어진다. 입력의 모든 값을 오름차순으로 담는다.

## 연습용 자체 예제 3
입력 매개변수:
```text
arr = [2, 5, 7]
divisor = 4
```
반환값:
```text
[-1]
```
설명: 4로 나누어떨어지는 원소가 없으므로 특별한 반환 규칙을 적용한다.

## Rider에서 연습하기
공유 `Daily_Algoithm/Daily_Algoithm.sln`에서 날짜가 포함된 프로젝트를 선택한다. `DivisibleNumbers.cs`는 작성 전까지 0바이트다. 공식 메서드 형식으로 풀고, 로컬 콘솔 실행이 필요하면 테스트용 진입점을 직접 추가할 수 있다. 공식 제출에는 해당 플랫폼 형식의 `Solution`을 사용한다. 별도의 콘솔 연습용 입력 규칙은 추가하지 않았다.
