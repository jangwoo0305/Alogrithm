
**알고리즘 : 그리디, 정렬**  
난이도: 초급~중급 · 예상 풀이 시간: 30~60분

## 사전 학습 포인트

- 그리디 알고리즘의 개념과 선택의 정당성
    
- 구간의 시작·종료 시각과 겹침의 정의
    
- 여러 기준을 이용한 정렬
    

## 출처

창작 문제

## 문제 설명

하루 동안 `N`개의 체험 수업이 열린다. `i`번 수업은 `S_i` 시각에 시작하여 `E_i` 시각에 끝난다. 모든 수업의 장소는 같으며 이동 시간은 없다.

수업을 선택하면 시작부터 끝까지 참여해야 한다. 동시에 두 수업에 참여할 수 없다. 단, **한 수업이 끝나는 시각과 다른 수업이 시작하는 시각이 같다면 연속으로 참여할 수 있다.**

참여할 수 있는 수업의 최대 개수를 구하라.

같은 시간에 열리는 수업도 각각 별개의 수업이지만, 시간이 겹치므로 동시에 선택할 수 없다.

## 입력 형식

첫째 줄에 수업 수 `N`이 주어진다.

다음 `N`개 줄에 각 수업의 시작 시각 `S_i`와 종료 시각 `E_i`가 공백으로 구분되어 주어진다. 수업은 시간순으로 주어지지 않을 수 있다.

## 출력 형식

참여할 수 있는 수업의 최대 개수를 한 줄에 출력한다.

## 제약 조건

- `1 ≤ N ≤ 200,000`
    
- `0 ≤ S_i < E_i ≤ 1,000,000,000`
    
- 모든 입력값은 정수이다.
    

## 입출력 예시

### 예시 1 — 일반적인 경우

입력:

```
6
3 5
0 6
5 7
1 3
7 9
4 8
```

출력:

```
4
```

설명: `(1, 3)`, `(3, 5)`, `(5, 7)`, `(7, 9)` 수업에 참여할 수 있다. 5개 이상 참여할 수 있는 조합은 없다.

### 예시 2 — 모든 수업이 서로 겹치는 경우

입력:

```
4
2 6
1 5
3 7
2 6
```

출력:

```
1
```

설명: 어떤 두 수업을 선택해도 시간이 겹치므로 하나만 참여할 수 있다.

### 예시 3 — 수업이 하나인 경우

입력:

```
1
0 1
```

출력:

```
1
```

설명: 유일한 수업에 참여할 수 있다.
