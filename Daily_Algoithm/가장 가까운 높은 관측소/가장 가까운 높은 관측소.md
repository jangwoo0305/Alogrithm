# 가장 가까운 높은 관측소

**알고리즘 : 단조 스택**  
난이도: 초급~중급 · 예상 풀이 시간: 30~60분

## 사전 학습 포인트

- 스택의 후입선출(LIFO)과 기본 연산
- 단조 스택의 개념과 같은 값의 처리
- 분할 상환 분석과 시간 복잡도

## 출처

창작 문제

## 문제 설명

일직선 위에 `N`개의 관측소가 왼쪽에서 오른쪽으로 세워져 있다. 관측소 번호는 왼쪽부터 1번부터 `N`번까지이며, `i`번 관측소의 높이는 `H_i`이다.

각 관측소는 **자신보다 왼쪽에 있으며, 높이가 자신의 높이 이상인 관측소**에 보고서를 보낸다.

조건에 맞는 관측소가 여러 개라면 가장 가까운 관측소, 즉 번호가 가장 큰 관측소를 선택한다. 조건에 맞는 관측소가 없으면 보고서를 보내지 않는다.

각 관측소의 보고 대상 번호를 구하라. 보고서를 보내지 않는 경우에는 `0`으로 표시한다. **높이가 같은 관측소도 보고서를 받을 수 있다.**

## 입력 형식

첫째 줄에 관측소의 수 `N`이 주어진다.

둘째 줄에 높이 `H_1, H_2, …, H_N`이 공백으로 구분되어 주어진다.

## 출력 형식

1번부터 `N`번 관측소까지, 각각의 보고 대상 번호를 공백으로 구분하여 한 줄에 출력한다.

## 제약 조건

- `1 ≤ N ≤ 200,000`
- `1 ≤ H_i ≤ 1,000,000,000`
- 모든 입력값은 정수이다.

## 입출력 예시

### 예시 1 — 일반적인 경우

입력:
```text
5
6 9 5 7 4
```

출력:
```text
0 0 2 2 4
```

설명: 1번은 왼쪽에 관측소가 없다. 2번의 왼쪽에는 높이가 9 이상인 관측소가 없다. 3번과 4번은 2번에 보고한다. 5번은 조건에 맞는 관측소 중 가장 가까운 4번에 보고한다.

### 예시 2 — 높이가 같은 경우

입력:
```text
4
8 8 3 8
```

출력:
```text
0 1 2 2
```

설명: 2번은 높이가 같은 1번에 보고한다. 3번은 2번에 보고한다. 4번의 왼쪽에서 높이가 8 이상인 관측소는 1번과 2번이며, 더 가까운 2번을 선택한다.

### 예시 3 — 관측소가 하나인 경우

입력:
```text
1
100
```

출력:
```text
0
```

설명: 왼쪽에 관측소가 없으므로 보고서를 보내지 않는다.
