- 난이도: 하~중(학습용 추정, 공식 등급 미확인)

## 사전학습 개념
- 큐의 선입선출과 재삽입
- 배열 인덱스와 대상 식별
- 우선순위 비교

## 문제 설명
여러 프로세스가 입력 순서대로 실행을 기다린다. 각각 정수 우선순위를 가지며, 숫자가 클수록 더 높은 우선순위다. 다음 규칙을 반복할 때 지정한 프로세스가 몇 번째로 실행되는지 구한다.

먼저 대기열 맨 앞의 프로세스를 꺼낸다. 나머지 대기열에 그것보다 우선순위가 높은 프로세스가 하나라도 있으면, 꺼낸 프로세스를 실행하지 않고 맨 뒤로 보낸다. 더 높은 프로세스가 없다면 즉시 실행하고 대기열에서 완전히 제거한다.

같은 우선순위는 더 높은 것으로 취급하지 않는다. 뒤로 보내는 동작은 실행 횟수에 포함하지 않는다. 우선순위가 같아도 서로 다른 프로세스이므로, 입력에서 지정한 대상의 신원을 끝까지 구분해야 한다. 반환하는 실행 순서는 1부터 센다.

## 공식 C# 제출 형식
Solution 클래스의 메서드를 구현한다.
```csharp
public int solution(int[] priorities, int location)
```
- priorities[i]: 처음 i번째에 있던 프로세스의 우선순위.
- location: 대상의 최초 인덱스이며 0부터 시작한다.
- 반환값: 대상의 실행 순서(1부터 시작).
- 공식 제출은 함수형이며 별도 표준입출력이 없다.

## 제약
- priorities 길이: 1~100.
- 우선순위: 1~9.
- location: 0~(배열 길이-1).
- 설명은 자체 서술이며 공식 원문은 출처 링크에서 확인한다.

## 연습용 자체 예제
| priorities | location | 반환값 |
|---|---|---|
| [3,1,2] | 1 | 3 |
| [2,2,2] | 2 | 3 |
| [1,3,2,3] | 0 | 4 |

1. 최초 인덱스 0, 2, 1 순서로 실행되므로 대상은 세 번째다.
2. 더 높은 우선순위가 없으므로 최초 순서대로 실행된다.
3. 최초 인덱스 1, 3, 2, 0 순서로 실행되므로 대상은 네 번째다.

세 예제는 독립 검산한 자체 연습 데이터다.
